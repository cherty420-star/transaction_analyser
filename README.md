# Transaction Analyser

Проект для анализа банковских транзакций из Excel-файла.

## 📋 Функциональность

### Веб-страницы
- **Главная страница**: Отображает статистику по картам, топ транзакций, курсы валют и цены акций

### Сервисы
- **Инвесткопилка**: Расчет суммы для инвестирования через округление транзакций
- **Простой поиск**: Поиск транзакций по описанию или категории

### Отчеты
- **Траты по дням недели**: Анализ средних трат по дням недели за последние 3 месяца
